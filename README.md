# 🎨 Relatório Gerencial de Vendas Elegante com Power BI

Projeto desenvolvido para o desafio prático **"Criando Um Relatório Gerencial de Vendas Elegante com Power BI"** do bootcamp **Universia - Primeiros Passos em Power BI** na plataforma **DIO (Digital Innovation One)**.

---

## 📌 Objetivos do Desafio

O objetivo deste projeto é elevar o nível de design e interatividade do relatório de vendas construído a partir da base de dados *Financial Sample*, aplicando técnicas avançadas de experiência do usuário (UX/UI) dentro do Power BI Desktop.

### 🎯 Requisitos Implementados

1. **Estrutura e Layout Elegante:** Organização de cards, imagens, molduras e alinhamento visual moderno.
2. **Navegação por Botões:** Ações de botões configuradas para alternar entre páginas do relatório sem depender da barra inferior.
3. **Indicadores (Bookmarks):** Alternância dinâmica entre visuais/gráficos sobre um mesmo assunto na mesma área da tela.
4. **Segmentadores de Dados (Filtros):** Filtros interativos associados a ícones/imagens corporativas.
5. **Relatório Multi-Páginas:** Estruturação em duas páginas complementares focadas na jornada analítica do usuário.

---

## 📐 Estrutura do Relatório

* **Página 1 - Visão Executiva & Navegação:**
  * Menu lateral/superior com botões de ação e navegação.
  * Segmentadores estilizados por ano, país e segmento.
  * Área principal interativa utilizando **Bookmarks** para trocar o tipo de visualização (ex: alternar entre visão de gráfico e visão de tabela/mapa).

* **Página 2 - Detalhamento Gerencial:**
  * Painel focado em detalhamento de margens, produtos mais rentáveis e performance por canal.
  * Botão de retorno rápido para a página inicial.

---

## 🛠️ Recursos de Interatividade Utilizados

* **Painel de Seleção (`Selection Pane`):** Para controlar a visibilidade dos objetos e camadas na tela.
* **Painel de Indicadores (`Bookmarks Pane`):** Para capturar o estado dos visuais e associar aos botões de navegação/troca de exibição.
* **Ações de Botões (`Button Actions`):** Configuração de navegação de página e acionamento de bookmarks.
